David Richter

Hi!

I am interested in programming language theory and practice, and correct and efficient compilers for domain-specific languages using functional programming and strong types. Usually, I write Lean proofs or Scala programs.

You can find my email at my university page, or in any of my published papers.

Research Projects#

An overview of my research grouped by topic. See Research for the full chronological list of publications and preprints, and Teaching for all courses and supervised theses.

Choreographic Programming Write a whole distributed system as one script, and let the compiler split it up. Incremental Programming Compilers that turn plain functional code into computations that redo only what changed. Type Systems & Mechanized Proofs Types catch bugs before a program runs, and stop humans and bots alike from doing nonsense. Compilers for Machine Learning Derive and prove what ML frameworks hard-code, and search for the equations that generated the data.
