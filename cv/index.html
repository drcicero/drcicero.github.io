Research Interests#

Programming languages; type systems; dependently typed programming and proof assistants (Lean, Coq/Rocq); mechanized metatheory; functional programming; effects and monads; compilers for domain-specific languages (arrays, automatic differentiation, incremental computation); choreographic programming and session types; verified compilation.
